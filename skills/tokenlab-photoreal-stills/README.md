# TokenLab Photoreal Stills

- Category: `image`
- License: MIT

Makes realistic photos of people, places, food, and scenes from a written brief. The skill picks a photoreal TokenLab image model, writes the prompt like a photographer, and uses `tokenlab-run` for the calls.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-photoreal-stills -y
```

Agents should use `SKILL.md`.

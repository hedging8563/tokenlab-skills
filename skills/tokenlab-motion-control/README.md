# TokenLab Motion Control

- Category: `video`
- License: MIT

Makes a character from one image perform the motion of a reference video. The skill checks the inputs, estimates the cost from the motion clip length, and uses `tokenlab-run` for the contract, call, and polling.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-motion-control -y
```

Agents should use `SKILL.md`.

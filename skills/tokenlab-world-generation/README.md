# TokenLab World Generation

- Category: `3d`
- License: MIT

Turns text, images, a panorama, or a video into an explorable 3D world with a viewer link, splats, and a collider mesh. The skill drafts on the low-cost world model first, then makes the final world, and uses `tokenlab-run` for the async calls.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-world-generation -y
```

Agents should use `SKILL.md`.

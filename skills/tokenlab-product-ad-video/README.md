# TokenLab Product Ad Video

- Category: `video`
- License: MIT

Turns a product photo or a brief into short ad clips that keep the product exact. The skill routes each shot (image-to-video, reference-to-video, or text-to-video) to a live TokenLab video model and uses `tokenlab-run` for the calls.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-product-ad-video -y
```

Agents should use `SKILL.md`.

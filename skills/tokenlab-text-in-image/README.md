# TokenLab Text in Image

- Category: `image`
- License: MIT

Makes posters, packaging, signs, and UI mockups with exact, legible words, and fixes wrong text in an existing image. The skill routes to text-strong TokenLab image models and checks the spelling of every word.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-text-in-image -y
```

Agents should use `SKILL.md`.

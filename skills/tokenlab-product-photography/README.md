# TokenLab Product Photography

- Category: `image`
- License: MIT

Turns a product photo or a brief into studio, lifestyle, or hero images. The skill routes each stage (generate or restage, cut out, replace background) to a live TokenLab image model and uses `tokenlab-run` for the calls.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-product-photography -y
```

Agents should use `SKILL.md`.

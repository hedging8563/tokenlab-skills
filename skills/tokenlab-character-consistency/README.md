# TokenLab Character Consistency

- Category: `image`
- License: MIT

Keeps one character, mascot, or product the same across new images and short clips. The skill makes or takes one anchor image, then generates each new scene from it with reference-image models, and uses `tokenlab-run` for the calls.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-character-consistency -y
```

Agents should use `SKILL.md`.

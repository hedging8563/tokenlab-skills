# TokenLab Cinematic Video

- Category: `video`
- License: MIT

Makes cinematic shots from text or a still image with film camera language. The skill plans one clip per shot, picks a live TokenLab text-to-video or image-to-video model, and uses `tokenlab-run` for the contract, cost estimate, call, and polling.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-cinematic-video -y
```

Agents should use `SKILL.md`.

# TokenLab Music

- Category: `audio`
- License: MIT

Makes songs, instrumentals, loops, and sound effects from a brief. The skill picks a live TokenLab music model for the job (full song or short clip), writes the brief in that model's fields, and uses `tokenlab-run` for the async calls.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-music -y
```

Agents should use `SKILL.md`.

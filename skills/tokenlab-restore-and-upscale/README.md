# TokenLab Restore and Upscale

- Category: `image`
- License: MIT

Makes a photo larger and sharper, and repairs old or damaged photos. The skill routes upscaling to dedicated upscale models and repairs to an edit model, and uses `tokenlab-run` for the calls.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-restore-and-upscale -y
```

Agents should use `SKILL.md`.

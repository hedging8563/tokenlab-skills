# TokenLab Native Endpoints

- Category: `coding`
- License: MIT

Guides agents through TokenLab native Responses, Anthropic Messages, Gemini, media, audio, embeddings, rerank, and translation routes.

Recommended non-interactive install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-native-endpoints -y
```

Agents should use `SKILL.md`.

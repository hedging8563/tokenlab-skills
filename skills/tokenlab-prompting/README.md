# TokenLab Prompting

- Category: `foundation`
- License: MIT

Prompt craft for each model family in the TokenLab catalog: FLUX, Nano Banana and Gemini image, GPT image, Seedream, Recraft, Qwen image, Ideogram, Seedance, Kling, Veo, Hailuo, Wan, PixVerse, Grok Imagine, Suno, MiniMax music, Stable Audio, and the TTS voices. Each family section names its official source and the model IDs it covers. Other skills point here when they need to write or fix a prompt.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-prompting -y
```

Agents should use `SKILL.md`.

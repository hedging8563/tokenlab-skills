# TokenLab Edit Video

- Category: `video`
- License: MIT

Restyles or changes an existing video clip with a prompt. The skill picks a live TokenLab video-to-video model by clip length and reference needs, and uses `tokenlab-run` for the contract, cost estimate, call, and polling.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-edit-video -y
```

Agents should use `SKILL.md`.

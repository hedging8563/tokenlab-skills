# TokenLab Talking Avatar

- Category: `video`
- License: MIT

Turns a portrait and a script or voice recording into a talking-head video. The skill chooses between an audio-driven avatar model and a video model that speaks a quoted line, and uses `tokenlab-run` for speech, the contract, cost estimate, call, and polling.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-talking-avatar -y
```

Agents should use `SKILL.md`.

# TokenLab Logos and Vectors

- Category: `image`
- License: MIT

Makes logo marks, icons, and flat graphics, and converts them to SVG. The skill generates a raster mark, vectorizes it with a TokenLab vectorizer, and uses `tokenlab-run` for the calls.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-logos-and-vectors -y
```

Agents should use `SKILL.md`.

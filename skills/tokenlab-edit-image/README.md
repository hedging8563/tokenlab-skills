# TokenLab Edit Image

- Category: `image`
- License: MIT

Makes one targeted change to an existing image: add, remove, replace, recolor, cut out, swap the background, or extend the frame. The skill picks the edit model by the type of change and uses `tokenlab-run` for the calls.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-edit-image -y
```

Agents should use `SKILL.md`.

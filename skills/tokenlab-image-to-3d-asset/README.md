# TokenLab Image to 3D Asset

- Category: `3d`
- License: MIT

Turns a photo or a text description into a downloadable 3D model. The skill prepares a clean single-object input, picks a live TokenLab 3D model for the use, and uses `tokenlab-run` for the async job and result files.

Install:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-image-to-3d-asset -y
```

Agents should use `SKILL.md`.
